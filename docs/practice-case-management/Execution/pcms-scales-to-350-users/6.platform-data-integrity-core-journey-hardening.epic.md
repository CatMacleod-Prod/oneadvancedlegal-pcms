# Platform Data Integrity & Core Journey Hardening

## Strategic Context
Ensuring data integrity under high-volume concurrency is as essential as transaction speed. Hardening critical background sync routines, validating session eviction for dead connections, and stabilizing matter/audit workflows prevents data corruption and memory leaks as concurrent usage scales to 350 users.

## Success Criteria
- Zero duplicate entries or resurrection anomalies during concurrent Mark-for-Archiving operations.
- 100% deletion synchronization parity between PCMS document records and SharePoint storage.
- Stable memory plateau across 30+ user soak tests with zero out-of-memory worker process crashes.

## Scope

### In Scope
- Mark-for-Archiving data integrity safeguards, duplicate-insert guards, and resurrection checks (RISK-01).
- Document Sync delete-path completeness verification and reconciliation reporting (RISK-02).
- Production-hardening, automated testing, and regression suites for core Matter/Audit journeys (MAJ-01).
- Layer 2 and Layer 3 load validation for Wisej idle and dead-client server-side session eviction (XCUT-06).
- Commit and deployment verification for uncommitted production hotfixes (XCUT-11).

### Out of Scope
- Full rebuild of the document synchronization pipeline.
- End-to-end archiving policy lifecycle redesign.

## Acceptance Criteria
WHEN a matter record is marked for archiving, the Data Access Layer SHALL execute deduplication checks atomically before committing state changes.

WHEN a document is deleted within PCMS, the Document Sync Provider SHALL verify deletion against SharePoint before updating the document record status.

WHILE user sessions remain idle beyond threshold limits, WHEN the Session Eviction Monitor runs, the Application Server SHALL release session memory without dropping active connected clients.

## Business Rules
- Failed document delete events must be logged to a dead-letter reconciliation queue for automated retry.
- Session eviction must never terminate active long-running foreground document transfers.

## Dependencies
- Non-prod SQL server access to extract deployed procedure definitions for source control alignment (XCUT-11).
- JMeter script fixes applied across the 10 affected canonical test journeys (XCUT-08).
