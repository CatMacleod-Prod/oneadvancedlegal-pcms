# Unified Billable Time Logging

## Strategic Context
Accurate time recording during client email drafting is essential for law firm revenue realization. Fee earners require an explicit, reliable time-capture mechanism during email composition in Classic Outlook that mirrors the experience in New Outlook, ensuring session persistence and preventing unbilled administrative effort.

## Success Criteria
- Log Time during compose works end-to-end in Classic Outlook: time recorded upon clicking "Save Time", value persists across compose session, and user is shown existing value on re-open.
- 100% parity in time-logging interface and activity codes between Classic and New Outlook.
- Time records post cleanly to PCMS Time Ledger upon email dispatch.

## Scope

### In Scope
- Explicit "Save Time" UI modal and task pane panel in Classic Outlook compose mode.
- Duration, activity code, billing rate category, and narrative fields.
- Session state caching and draft persistence across compose window minimize/re-open cycles.
- Direct posting of validated time entries to PCMS Time Ledger on email dispatch.

### Out of Scope
- Automated passive background time tracking without fee-earner confirmation.
- Direct invoice generation from the compose window.

## Acceptance Criteria
WHEN a fee earner enters billable duration, narrative, and activity code and clicks "Save Time" in Classic Outlook compose, the Add-In SHALL persist the time record to the compose session state.

WHERE a fee earner saves a time entry, closes or minimizes the compose draft, and subsequently re-opens it, the Add-In SHALL display the previously saved time values in the task pane.

WHEN the email is sent, the Add-In and Sync Service SHALL commit the saved time record to the PCMS Time Ledger.

IF mandatory billing fields (matter, duration, activity code) are incomplete when "Save Time" is clicked, THEN the Add-In SHALL highlight missing fields and prevent save until valid.

## Business Rules
- Time recording during compose must be explicit via fee-earner action ("Save Time") rather than implicit timer tracking.
- Saved compose time entries must be editable by the fee earner at any point prior to email dispatch.

## Dependencies
- PCMS Time & Billing Ledger API endpoints.
- Matter fee structure validation service.
