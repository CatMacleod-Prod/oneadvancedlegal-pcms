# Press Release

## Headline
PCMS Delivers Seamless Cloud-Native BundleDocs Integration to Streamline Professional Court Bundling

## Summary
The Practice Case Management System (PCMS) introduces direct integration with BundleDocs Cloud API within the paginated document history control. Fee earners and legal support staff can now select case documents in PCMS, export them directly into BundleDocs, and prepare compliant electronic court bundles in a single workflow without local desktop software dependencies.

## Problem Statement
Mid-market law firms migrating from legacy desktop solutions like ALB lose critical bundling capabilities when moving to web platforms limited to basic PDF merging. Legal teams are forced to download case files individually, assemble bundles across disconnected third-party tools, and re-upload completed files manually. This multi-step process introduces administrative drag, increases error rates in document pagination, and delays court filing deadlines.

## Solution
PCMS bridges the capability gap by integrating directly with the BundleDocs Cloud API via OAuth2. Users select matter documents within PCMS Document History, click "Create Bundle with BundleDocs", and stream files directly to BundleDocs without intermediate local downloads. BundleDocs opens immediately in a new browser tab with all selected files pre-loaded into a dedicated section, enabling fee earners to index, paginate, and generate court-ready bundles seamlessly.

## Customer Impact

| Key Features | Key Benefits | Value & Impact Delivered |
|---|---|---|
| 1-Click BundleDocs Cloud Export | Direct browser-based export to BundleDocs without desktop agent installation | Saves 1-2 hours per complex court bundle assembly |
| Direct SharePoint Stream Provisioning | Files stream securely from SharePoint via Microsoft Graph API without local disk storage | Eliminates local storage security risks and file transfer corruption |
| Context Menu Workflow Integration | Native "Create Bundle with BundleDocs" action directly in paginated document history | Removes barrier for firms migrating from ALB to PCMS |
