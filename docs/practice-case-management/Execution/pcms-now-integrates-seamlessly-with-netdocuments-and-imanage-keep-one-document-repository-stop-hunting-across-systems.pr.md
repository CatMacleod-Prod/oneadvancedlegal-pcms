# One document repository

## Release Information
**Product/Module:** PCMS Core Application with Document Management & Integration Service
**Version:** Q4 FY26

## Headline
PCMS now integrates seamlessly with NetDocuments and iManage—keep one document repository, stop hunting across systems.

## Summary
Legal practices using NetDocuments or iManage can now work alongside PCMS while maintaining a single, unified document repository. Teams eliminate the friction of hunting across multiple systems and duplicating files, enabling fee earners to focus on billable work instead of administrative overhead.

## Problem Statement
Mid-market and large legal practices operate across fragmented document management ecosystems. Firms using NetDocuments or iManage alongside PCMS are forced to maintain parallel document repositories, duplicate critical files across systems, and waste billable time searching for the authoritative version of a document. This fragmentation breaks workflow continuity, introduces compliance risk, and drains profitability through non-billable administrative burden.

## Solution
PCMS now integrates natively with NetDocuments and iManage through pluggable microservice hooks in the Document Management & Integration Service. Document metadata, version control, and cross-jurisdictional classifications sync seamlessly across systems in real time. Fee earners access all documents—whether filed in NetDocuments, iManage, or PCMS—from a single unified interface, eliminating duplication and search friction while maintaining full audit trails and SRA/Law Society of Scotland compliance.

## Customer Impact

|---|---|---|
| Native NetDocuments & iManage integration via pluggable microservice hooks | Teams work from one unified document view across all systems | Eliminate 1.5–2 hours per day of unbillable file-hunting and duplication overhead |
