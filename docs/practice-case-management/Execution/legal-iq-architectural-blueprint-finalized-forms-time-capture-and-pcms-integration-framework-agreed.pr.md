# Press Release

## Headline
Time capture, legal forms and the practice management system (PCMS) will begin moving to a common, modern platform, with updated frameworks

## Summary
By the end of Q4 FY26, Legal IQ will establish and secure agreement on a unified architectural blueprint that integrates Forms management, Time Capture functionality, and the Practice Case Management System (PCMS) onto a common, modern platform. This blueprint defines the technical foundation, modern frameworks, data governance models, and integration boundaries required to enable seamless cross-system workflows across UK legal practices. The agreement eliminates technical ambiguity, unlocking downstream development roadmaps for automated client onboarding, matter-linked time tracking, and real-time ledger synchronization.

## Problem Statement

Mid-market and large UK legal practices currently operate Forms, Time Capture, and PCMS as loosely coordinated systems, creating fragmented workflows where client intake data, billable time records, and matter financials require manual reconciliation. Without a unified architectural blueprint, development teams lack clear integration boundaries, data ownership models, and API contracts, leading to duplicate effort, compliance risk, and delayed delivery of cross-system automation. Legal practices cannot efficiently link client onboarding (Forms) → matter activation (PCMS) → time billing (Time Capture) in a single, auditable workflow.

## Solution
Legal IQ will establish an agreed architectural blueprint that transitions core capabilities to a modern platform framework:
- **Forms Integration Layer:** Client intake data models, eIDV/AML checkpoints, and bi-directional synchronization with PCMS client records.
- **Time Capture Integration Layer:** Matter-linked time entry schemas, real-time sync to PCMS financial ledgers, and LAA/SLAB billing export pipelines.
- **Data Governance & API Contracts:** Unified entity definitions (clients, matters, users, jurisdictions), master data ownership, and REST API specifications for cross-system communication.
- **Compliance & Audit Boundaries:** SRA and Law Society of Scotland accounts rule enforcement, digital authorization workflows, and immutable audit trails spanning all three systems.

## Customer Impact

| Key Features | Key Benefits | Value & Impact Delivered |
|---|---|---|
| Unified Client Onboarding → Matter Activation Workflow | Fee earners create clients via Forms, auto-populate PCMS matter records without manual re-entry | Recovers 15–20 minutes per matter creation; eliminates data re-keying errors |
| Matter-Linked Time Entry with Real-Time Billing Sync | Solicitors capture time against PCMS matters; automatically reconciles to legal accounts ledger | Eliminates end-of-month time/billing reconciliation friction; improves cash flow visibility |
| Master Data Governance Framework | Single agreed definition of clients, matters, users, and jurisdictions across all three systems | Reduces compliance risk; enables consistent SRA/SLAB audit trails; prevents conflicting data states |
| Documented API Contracts & Integration Boundaries | Development teams share agreed REST API specifications, event schemas, and data ownership rules | Accelerates future enhancements; reduces rework; enables parallel feature delivery across teams |
| Compliance-First Architecture | Blueprint includes SRA Accounts Rules, Law Society of Scotland requirements, and LAA billing export pathways built into integration design | De-risks regulatory compliance; shortens certification cycles; builds customer confidence |
