# Press Release

## Headline

IQ Legal Advances PCMS Architecture with Core System Performance Improvements in the move to supporting scalability for 350+ User Law Practices

## Summary

IQ Legal today announces targeted architectural and performance improvements across its Practice & Case Management System (PCMS) to support growing multi-office law firms across England and Wales. These systematic backend and data-layer enhancements eliminate bottlenecks, lower query latency, and optimize resource handling to ensure reliable, high-concurrency performance in the move towards supporting 350+ active fee earners and staff.

## Problem Statement

Mid-market law firms scaling past 50 to 350+ staff encounter severe performance degradation, database lock contention, and slow document retrieval in legacy case management systems. During peak billing windows and high-volume matter progression, system lag and record contention disrupt fee earners and cashiers, risking compliance exposure, reducing billable utilization, and capping practice growth across multi-office operations.

## Solution

As part of the IQ Legal product suite, this release delivers comprehensive system and infrastructure enhancements across PCMS, including database indexing and query optimization, dynamic microservice scaling, distributed Redis caching for active matter files, and resilient rate-managed composite APIs. These improvements ensure predictable sub-second system response, eliminate downtime during high-load periods, and deliver seamless scalability for expanding legal practices.
