# Press Release

## Headline

OneAdvanced extends modern New Outlook Add-In capabilities to Classic Outlook desktop users

## Summary

OneAdvanced is expanding its proven New Outlook Add-In to support Classic Outlook (Win32 desktop), delivering a unified email filing and matter management experience across all Microsoft Outlook clients. 

Firms running Classic Outlook can now access the same seamless compose, email filing, and explicit time logging workflows already established in New Outlook. This extension bridges the desktop gap for mid-market legal practices transitioning between environments, ensuring feature parity without disrupting established fee-earner habits.

## Problem Statement

While the OneAdvanced Outlook Add-In delivers modern, automated matter filing and time capture in New Outlook and Outlook on the Web, mid-market UK legal practices still rely heavily on Classic Outlook (Win32 desktop) for day-to-day operations. 

Previously, key capabilities—specifically filing during new email composition and capturing billable time during compose—were unavailable in Classic Outlook due to differences in desktop event architecture. This created workflow fragmentation and prevented firms with mixed or legacy desktop estates from fully adopting the modern Add-In experience.

## Solution

This release extends the existing New Outlook Add-In architecture to natively support Classic Outlook (Win32), establishing complete dual-client parity.

By leveraging single-value extended properties alongside the Exchange Sync Service, the Add-In reliably captures matter metadata during Classic Outlook compose workflows and syncs sent correspondence directly into PCMS. In addition, the unified explicit "Save Time" action provides consistent, reliable billable time capture across both Classic and New Outlook environments. Runtime platform detection routes users automatically to the appropriate pipeline while preserving all existing New Outlook capabilities.
