# Agents for personal injury fee earners

## Release Information
**Product/Module:** PCMS Personal Injury Workflow Automation
**Version:** Q2 FY27

## Headline
Intelligent agents now automate routine personal injury tasks, freeing fee earners to focus on case strategy and client advice.

## Summary
We are releasing AI-driven agents that intelligently handle manual, repetitive tasks within personal injury workflows starting in Q2 FY27. Fee earners reclaim up to 2 hours per day previously spent on administrative work, enabling practices to increase billable capacity and case throughput per fee earner without expanding headcount.

## Problem Statement
Personal injury fee earners spend disproportionate time on non-billable administrative tasks—document assembly, case status updates, evidence organization, and compliance checklist management—that delay case progression and reduce billable utilization. This manual overhead limits the number of cases each fee earner can actively manage and diverts attention from high-value advice and case strategy that clients expect and that drives firm profitability.

## Solution
Our new agent framework seamlessly integrates with existing personal injury workflows, automatically executing repetitive tasks that fee earners would otherwise perform manually. Agents intelligently route evidence, assemble documentation bundles, update case milestones, and validate compliance requirements in real time. Fee earners retain full visibility and control while agents eliminate context-switching and keyboard time, allowing practitioners to dedicate more cognitive energy to strategy, negotiation, and client relationships.

## Customer Impact

| Key Features | Key Benefits | Value & Impact Delivered |
|---|---|---|
| Automated evidence and document assembly | Eliminates manual file organization and reduces document handling errors | Cases prepared 40% faster with near-zero rework |

## Internal Notes
Agents initially target high-volume, repeatable personal injury workflows (RTA, employer's liability, public liability). Phase 1 focuses on task delegation and document assembly; Phase 2 (Q3) will expand to automated settlement communications and LAA fixed-fee claim optimization. Success metrics: fee earner capacity gain (hours reclaimed), case throughput lift, and compliance audit cycle reduction. Monitor early adoption feedback to inform Phase 2 scope and identify cross-practice workflow patterns for scaling to other disciplines.
