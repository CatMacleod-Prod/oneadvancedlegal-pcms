# AI Workflow Generation Utility Pipeline

## Strategic Context

Legal workflow development and legacy migration have historically been constrained by manual business logic extraction from legacy PCMS codebases (ALB, Partner for Windows), error-prone API mapping, and tedious manual authoring of Flowable BPMN XML and form definitions. The 7-Stage AI Workflow Generation Utility automates process discovery, process map ingestion, API gap analysis, interactive browser-based SME review, and automated Flowable packaging with downstream iteration support. This utility is purpose-built as an internal accelerator for PCMS Solutions Architecture and Support Engineering teams to rapidly deliver bespoke workflows and expand residential conveyancing accelerator packs (Freehold, Leasehold, Unregistered Title, Shared Ownership) without exposing raw tooling or migration utilities to external customer tenants.

## Success Criteria

* 7-stage pipeline (Discovery, Process Map Ingestion, API Mapping, SME Review, Workflow Build, Packaging, Feedback Iteration) fully operational and accessible exclusively to internal solutions and support engineering teams.
* End-to-end automated conversion of legacy process maps (PDF, Visio, BPMN XML, ALB, P4W exports) into verified Flowable BPMN 2.0 packages with zero schema validation errors.
* Delivery and validation of expanded Residential Sale accelerator packs covering standard Freehold, Leasehold, Unregistered Title, and Shared Ownership conveyancing tracks.
* Automated testing harness executes dry-run simulation and step-by-step path validation across 100% of generated workflow packages prior to customer deployment.
* Internal workflow authoring and migration delivery cycle time reduced by over 75% compared to manual implementation.

## Scope

### In Scope

* Internal-Only Utility Access: Secure CLI and web console interfaces restricted via internal role-based access control (RBAC) to Solutions Architecture, Professional Services, and Support Engineering teams.
* Process Map Ingestion Engine: AI-driven ingestion and AST parsing of process maps and legacy documentation (PDF workflows, Microsoft Visio `.vsdx`, standard BPMN 2.0 XML, Advanced ALB schemas, and Tikit P4W workflow definitions).
* API Mapping & Gap Reporting: Automated mapping of extracted workflow decision nodes and tasks against PCMS REST endpoints with automated gap reporting for unmapped actions.
* Internal SME Review Portal: Self-contained browser-based staging portal enabling internal solutions engineers and legal SMEs to inspect, edit, and sign off on process logic, forms, and variables prior to packaging.
* Automated Testing & Simulation Harness: Execution engine simulating process execution paths, variable evaluations, task assignments, and API callouts with synthetic payload injection.
* Flowable Packaging & Downstream Regeneration: Automated compilation of versioned Flowable deployment archives (`.bar`/`.zip`) with targeted regeneration for iterative SME feedback.
* **Enhancement and Bug/Defect Fixes:**&#x20;
  * Role Type API to list results in alphabetical order for better UX (investigation on what the API returns currently to facilitate)
  * Allow picklist options to be available in picklist fields generated in a workflow via the utility

### Out of Scope

* External customer self-service access, direct tenant-admin access, or public customer-facing UI for the AI Workflow Generation Utility.
* Direct runtime modification of Flowable core engine binaries or platform kernel code.
* Non-legal CRM or generic non-legal enterprise accounting workflow extraction.
* End-user runtime execution outside the core PCMS workflow engine.

## Acceptance Criteria

WHEN an internal solutions engineer uploads a legacy process map (PDF), the Ingestion Engine SHALL extract all tasks, gateways, and data fields into a structured workflow intermediate representation within 45 seconds.

WHEN a Residential Sale workflow type is selected, the Utility SHALL scaffold the corresponding accelerator pack variant (Freehold, Leasehold, Unregistered, or Shared Ownership) with pre-mapped PCMS conveyancing endpoints.

WHERE an external customer or unauthenticated user attempts to access the Utility endpoints or SME review portal, the Access Controller SHALL reject the request with HTTP 403 Forbidden.

WHEN legacy business logic contains unmapped API actions, the Mapping Engine SHALL generate an API Gap Report highlighting missing PCMS endpoints and required composite wrappers.

WHEN workflow specifications are approved in the internal SME Review Portal, the Build Engine SHALL compile valid Flowable BPMN 2.0 XML and form schemas complying with Flowable 6.x/7.x standards.

WHEN a compiled workflow package is submitted to the Testing Harness, the Simulation Engine SHALL execute automated path-traversal validation and output a pass/fail verification report across all branches.

IF SME feedback requires modifications to a specific workflow step, THEN the Iteration Engine SHALL recompile only the affected downstream BPMN nodes and form definitions without resetting upstream stages.

## Business Rules

* The utility and its associated staging review portals must be isolated within the internal corporate VPC/VPN and restricted to authenticated internal team members.
* External law firm clients and end users must only receive finalized, validated accelerator packages deployed through standard PCMS release channels.
* Generated BPMN XML files must pass strict schema validation against Flowable BPMN 2.0 specifications prior to package compilation.
* All Residential Sale accelerator packs must comply with standard Law Society Conveyancing Protocol milestones and post-completion obligations.
* Workflow generation must be deterministic with immutable audit trails recording all SME sign-offs and AST generation prompts.

## Dependencies

* PCMS core API endpoint catalogue, conveyancing domain REST APIs, and OpenAPI specifications.
* Flowable BPMN engine schema definitions and deployment package specifications.
* Internal identity provider (IdP) integration for internal team authentication and RBAC enforcement.
* AI model inference gateway and document parsing microservices.
