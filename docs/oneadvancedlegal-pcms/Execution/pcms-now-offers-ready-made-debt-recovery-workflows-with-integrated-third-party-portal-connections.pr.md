# Debt recovery workflows

## Release Information
**Product/Module:** PCMS Core Application
**Version:** Q4 FY26

## Headline
PCMS Now Offers Ready-Made Debt Recovery Workflows with Integrated Third-Party Portal Connections

## Summary
Legal practices handling debt recovery can now launch cases faster with pre-configured workflows built directly into PCMS, complete with integrated connections to relevant third-party recovery portals. By eliminating manual setup and data re-entry across systems, debt recovery teams accelerate case throughput and recover valuable billable time previously lost to administrative overhead.

## Problem Statement
Debt recovery firms currently spend significant time configuring workflows from scratch for each new case, manually re-keying data between PCMS and third-party recovery portals, and managing disconnected systems that lack native integration. This fragmentation creates administrative friction, slows case progression, introduces data-entry errors, and diverts fee-earner capacity from billable recovery work to non-billable system administration.

## Solution
PCMS now provides ready-made debt recovery workflow templates that are pre-configured, tested, and ready to deploy immediately. These workflows include direct, bidirectional integrations with industry-standard third-party recovery portals where applicable, allowing case data to flow seamlessly between PCMS and external systems without manual re-keying. Fee earners simply select the recovery workflow template, initiate the case, and the system automatically synchronizes matter details, recovery actions, and status updates across all connected platforms.
