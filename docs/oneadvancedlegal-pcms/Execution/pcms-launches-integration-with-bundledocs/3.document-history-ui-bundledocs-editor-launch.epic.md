# Document History UI & BundleDocs Editor Launch

## Strategic Context
Fee earners and legal assistants manage case correspondence in the PCMS Paginated Document History control. Adding an intuitive right-click context menu item and real-time status feedback enables users to initiate court bundles in a familiar workflow, while automatically launching the web editor upon successful provisioning.

## Success Criteria
- "Create Bundle with BundleDocs" option available in document history right-click context menu.
- Real-time progress bar/status notifications displayed throughout the multi-step export process.
- Automatic browser tab launch to the specific BundleDocs editor URL upon completion.

## Scope

### In Scope
- Context menu modification in `PaginatedDocumentHistoryControl` with feature flag and license checks.
- Multi-select document validation (minimum 1 document selected).
- UI progress modal showing multi-step status ("Creating bundle...", "Uploading [File]...", "Opening editor...").
- Browser launch mechanism directing user to `https://app.bundledocs.com/bundle/{PartitionKey}/{RowKey}`.
- User-facing error notifications and toast alerts.

### Out of Scope
- Bi-directional bundle sync or bundle status list embedded inside PCMS UI (deferred to Phase 2).
- Re-opening or editing existing generated bundles from PCMS document history.

## Acceptance Criteria
WHEN one or more documents are selected in Document History AND BundleDocs integration is enabled, the UI SHALL display an active "Create Bundle with BundleDocs" item in the context menu.

WHEN BundleDocs is not enabled in firm settings, the UI SHALL display the menu item in a disabled state with a configuration tooltip.

WHEN the user clicks "Create Bundle with BundleDocs", the UI SHALL present a progress indicator displaying current document upload stages.

WHEN the bundling API process successfully completes, the UI SHALL open the BundleDocs editor URL in a new browser tab and display a completion message.

IF the bundling operation fails at any step, THEN the UI SHALL dismiss the progress indicator and present a clear error modal detailing the failure reason.

## Business Rules
- The context menu item must be hidden if the user lacks export permissions on the selected matter.
- The action requires at least one document selected in the grid.
- Existing "Create PDF Bundle" (basic Aspose merge) menu item must remain alongside the new option.

## Dependencies
- `PaginatedDocumentHistoryControl` core component.
- `BundleDocsCloudService` client and streaming orchestrator.
