# Matter progress and client update agents

## Release Information
**Product/Module:** PCMS Client Communication Automation
**Version:** Q4 FY26

## Headline
AI-Powered Matter Progress Tracking and Automated Client Updates Via WhatsApp and SMS

## Summary
We are releasing two integrated AI agents that transform how legal practices communicate with clients. The Matter Progress Agent continuously monitors matter status and milestones, while the Client Update Agent automatically composes and delivers regular, detailed progress updates directly to clients via WhatsApp and SMS—eliminating repetitive manual updates and reducing administrative overhead for fee earners.

## Problem Statement
Mid-market legal practices struggle with high-frequency client inquiries ("any news on my matter?") that interrupt fee earners and generate non-billable administrative time. Manual status updates require fee earners to interrupt billable work, draft communications, and manually send them—creating operational friction that diverts 2+ hours per day per partner from revenue-generating activity. Clients simultaneously feel under-informed because updates are reactive and sporadic rather than proactive and regular.

## Solution
The Matter Progress Agent intelligently tracks matter lifecycle events, milestone completion, court dates, document submissions, and status changes across the PCMS Core Application in real time. The Client Update Agent uses that progress data to automatically compose contextually rich, legally appropriate client updates and deliver them via WhatsApp and SMS on a schedule configured by the practice. Fee earners retain full oversight and can edit or suppress updates before delivery. The result is proactive, frequent client communication without manual fee-earner intervention.
