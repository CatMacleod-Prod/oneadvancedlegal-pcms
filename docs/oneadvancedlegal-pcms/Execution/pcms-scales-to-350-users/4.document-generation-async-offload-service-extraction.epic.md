# Document Generation Async Offload & Service Extraction

## Strategic Context
Document production and court bundling operations execute synchronous document merges and SharePoint Graph calls on interactive web server threads, triggering thread deadlocks and UI freezes. Offloading batch document operations onto an asynchronous queue and extracting document generation into a dedicated service is required to protect user responsiveness under high concurrency.

## Success Criteria
- Court bundling and bulk correspondence generation execute asynchronously with 0% impact on interactive UI responsiveness.
- P50 document assembly latency reduced to ≤ 5 seconds under full 350-user load.
- Core Document Generation Service extracted behind clean service interfaces with automated retry handling.

## Scope

### In Scope
- Completion of in-place async refactoring across remaining document paths (DOC-01).
- Queue infrastructure and offload mechanics for batch and heavy document generation journeys (DOC-02).
- Extraction of the core Document Generation Service behind service contracts (DOC-03).
- SharePoint and Microsoft Graph API async pre-fetch optimization.
- Document baseline performance reconfirmation across realistic matter file sizes (DOC-04).

### Out of Scope
- Document template design editor overhaul (DOC-05).
- Migration away from Microsoft SharePoint/OneDrive as the underlying document repository.

## Acceptance Criteria
WHEN a user initiates a court bundle or bulk document generation, the Document Production Orchestrator SHALL enqueue the job asynchronously and return immediate UI control to the user.

WHEN the Document Generation Service processes merge fields, the Integration Layer SHALL pre-fetch required Microsoft Graph metadata concurrently.

IF a transient network error occurs during SharePoint document transfer, THEN the Document Generation Service SHALL execute exponential-backoff retries up to 3 times before flagging a task failure.

## Business Rules
- Single-letter interactive creation must maintain real-time preview generation within 3 seconds.
- Batch generation queue workers must isolate document assembly memory to prevent web process recycling.

- `DocumentProductionUri` toggle verified in staging environments (GATE-05).
