# Re-mortgage Workflow and Partner Integrations

## Strategic Context
Re-mortgage workflows rely on fast, high-volume matter processing combined with precise external Land Registry interactions (OS1 priority searches and AP1 charge registrations) and partner cost logging. Manually switching to external web portals for Land Registry filings causes delays and cost reconciliation errors. Integrating Land Registry filings and automated InfoTrack cost feeds directly into PCMS streamlines the entire re-mortgage transaction lifecycle.

## Success Criteria
- Delivery of dedicated Re-mortgage transaction management endpoints and InfoTrack wrapping integrations across Sprints 11–14.
- Automated generation and submission of Land Registry OS1 priority searches and AP1 new charge registrations via InfoTrack.
- Bi-directional integration via Prismatic Flow 5 to automatically ingest InfoTrack search and disbursement costs into ConveyFinance.

## Scope

### In Scope
- Re-mortgage transaction details PUT (RM1) including linked transfer flags and completion dates.
- Land Registry OS1 priority search submission POST (RM2) via InfoTrack integration layer.
- Land Registry AP1 new charge registration POST (RM3) via InfoTrack integration layer.
- Automated ingestion of InfoTrack search costs into ConveyFinance records via Prismatic integration flows.

### Out of Scope
- Direct HMLR Business Gateway integration bypassing InfoTrack.
- Scotland Registers of Scotland (RoS) filings (explicitly out of scope for England & Wales release).
- Automated cashier disbursement postings (deferred to Completion Postings Epic).

## Acceptance Criteria
WHEN PUT /v1/matters/{matterId}/conveyancing/transaction is called, the Re-mortgage API Suite SHALL update transaction terms, property value, and anticipated completion dates, triggering financial recalculations where required.

WHEN an OS1 priority search is initiated via POST /v1/land-registry/os1, the Re-mortgage API Suite SHALL format and dispatch the request to the InfoTrack wrapping service and return the search tracking reference.

WHEN an AP1 charge registration is submitted via POST /v1/land-registry/ap1, the Re-mortgage API Suite SHALL record the registration submission against the matter and monitor registration status.

WHERE InfoTrack generates disbursement and search fee events, the integration flow SHALL automatically write cost line items directly into the matter's ConveyFinance ledger.

IF an external Land Registry request fails or times out, THEN the integration layer SHALL return appropriate failure diagnostics and support status polling.

## Business Rules
- OS1 priority search validity windows must be tracked to alert fee earners before protection expires.
- AP1 submissions must validate that mandatory mortgage deed attachments and title numbers are present before external dispatch.
- Ingested InfoTrack costs must match existing reference data categories and update the matter's live completion statement balances.

## Dependencies
- Common Conveyancing API Foundation (ConveyFinance PUT from Sprint 2).
- InfoTrack API access, credentials, and sandbox environment configuration.
- Prismatic integration engine connectivity.

## Open Questions
- Confirmation of InfoTrack commercial onboarding agreements and API credentials ahead of Sprint 11.
