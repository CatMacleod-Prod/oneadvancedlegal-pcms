# Press Release

## Headline

OneAdvanced launches AI-Powered Workflow Builder, debuting an end-to-end Client and Matter Inception accelerator alongside modernised API foundations

## Summary

OneAdvanced has launched an automated 7-stage AI workflow generation engine that converts existing process maps directly into executable, validated legal workflows within Flow. This new capability has been used to deliver an out-of-the-box, end-to-end Client and Matter Inception (CMI) accelerator pack, drastically accelerating time-to-value for mid-market law firms. Alongside these workflow innovations, OneAdvanced has modernised the underlying platform foundation by restructuring the PCMS API surface into 24 modular functional domains across 206 endpoints.

## Problem Statement

Mid-market law firms face severe administrative drag, delayed matter setup, and costly onboarding bottlenecks when orchestrating complex matter lifecycles. Legal teams and practice managers are burdened by the manual effort required to translate static PDF process maps into automated workflows, while non-technical users struggle with complex multi-step orchestration. As a result, fee earners lose 1.5 to 2 hours per day context-switching across disconnected verification tools, compliance checks, and matter intake steps.

Supporting these operational challenges, previous monolithic backend systems lacked the modular API boundaries needed for rapid extensibility and seamless third-party partner integrations.

## Solution

This release introduces an AI-first workflow generation and onboarding ecosystem:

* **7-Stage AI Workflow Generation Pipeline:** Automatically ingests standard PDF process maps and converts them into production-ready Flowable BPMN workflows. With automated AST discovery, PCMS API mapping, an SME web review interface, and automated packaging, firms can stand up tailored workflows without weeks of manual authoring.
* **End-to-End Client & Matter Inception (CMI) Accelerator:** A fully configured, out-of-the-box workflow built directly with the AI builder, covering complete client intake, automated verification/AML steps, matter creation, and task routing—backed by an interactive customer demonstration.
* **Unified Task Home Screen & Platform Hardening:** A consolidated dashboard unifying workflow and system tasks, complete with encrypted file transfer between Flow and PCMS, antivirus scanning, and systemic reliability enhancements.
* **Modular API Domain Architecture (Supporting Infrastructure):** Restructured 16 legacy domains into 24 modular, RESTful service domains across 206 endpoints, providing isolated deployment pipelines, granular gateway policies, and standardized partner integration contracts to power the workflow platform.
